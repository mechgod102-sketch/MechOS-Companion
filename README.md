# MechOS Companion Mobile 0.1.1

Flutter source for the Android + iPhone MechOS Companion app.

## New in v0.1.1 — Optimization Reports

The **Optimize** tab now provides a complete reporting flow for MechOS development/support:

- Run a live optimization scan from the paired MechOS PC or Steam Deck.
- Collect CPU, GPU (when supported), RAM, storage, temperature (when supported), session, MechOS version/channel, update state, and RadarAI state.
- Calculate an optimization score from 0–100.
- Show prioritized findings and recommended fixes.
- Generate a **1080×1920 full PNG** or **1080×1350 summary PNG** locally on the phone.
- Save report images to the phone's photo library in the **MechOS Reports** album.
- Open the system share sheet from the **Share to Discord** button so the image can be posted to your development Discord.
- Include a unique report ID and timestamp on every report image.

The image generator runs on the phone. System scan data is generated locally by the authenticated MechOS Bridge; missing sensors are marked unavailable rather than guessed.

## Existing companion features

- One-time-code pairing with a MechOS PC / Steam Deck.

## Build prerequisites

Use a current Flutter toolchain compatible with Dart 3.9+. Android builds can be created on Windows, Linux, or macOS. **iPhone/iOS builds require macOS with Xcode** for Apple signing/building.

## Generate Android + iOS host projects

The source archive intentionally keeps the Android/iOS host files generated by your installed Flutter SDK instead of freezing an old Flutter template.

```bash
./scripts/bootstrap-platforms.sh
```

That command runs `flutter create`, applies MechOS networking and report-gallery permissions, and downloads packages.

Then test:

```bash
flutter test
flutter run
```

Build Android APK:

```bash
flutter build apk --release
```

Android output:

```text
build/app/outputs/flutter-apk/app-release.apk
```

Build a Play Store bundle:

```bash
flutter build appbundle --release
```

Build iPhone on macOS:

```bash
flutter build ios --release
```

Then open `ios/Runner.xcworkspace` in Xcode, select your Apple signing team, and archive/install the app.

## Install or update the MechOS Bridge

From this project on the MechOS computer:

```bash
./scripts/install-bridge.sh
```

View the pairing code:

```bash
journalctl --user -u mechos-companion-bridge -n 30
```

Enter the computer's LAN address and six-digit pairing code on the phone. Default bridge port: **47831**.

## Optimization Report API

The phone requests:

```text
GET /v1/optimization/report
```

The bridge returns structured data including:

- report ID / generation time
- device / MechOS version / build channel
- session / RadarAI state
- optimization score
- CPU utilization
- GPU utilization when available via `nvidia-smi` or Linux DRM sysfs
- RAM utilization
- storage utilization
- temperature when a Linux sensor is available
- findings / severity
- recommended fixes

See `docs/API.md` for the API contract.

## Report image permissions

The bootstrap script configures the platform projects for gallery saving:

- Android: legacy write permission only for Android API 29 and below, plus API-29 album compatibility.
- iOS: photo-library add access and photo-library access required for saving to the **MechOS Reports** album.

The app asks for gallery permission only when **Save to Phone** is used.

## Security design

- The phone cannot send arbitrary shell commands.
- The bridge uses an explicit action allow-list.
- Pairing creates a random per-device bearer token.
- Mobile secrets go into OS-backed secure storage.
- Power/session actions require confirmation in the app.
- Optimization scans are read-only.
- Report PNG generation is local to the phone.
- v0.1.1 still uses authenticated local-network HTTP for trusted-LAN development. Before exposing the bridge beyond the local network, add authenticated TLS/certificate pinning.

## MechOS helper commands expected

- `mechos-update --check`
- `mechos-update --install`
- `mechos-session-select --mechscope`
- `mechos-session-select --desktop`
- `radarai status`
- `radarai scan --quick`
- `mechos-power-control --restart`
- `mechos-power-control --shutdown`

Missing helpers are reported to the app instead of falling back to arbitrary commands.

## Source validation

This package includes `scripts/validate_source.py` and a bridge report smoke test. The current build environment does not include the Flutter SDK, so a signed APK/IPA is not bundled in this source ZIP.

## GitHub build automation

This repository includes GitHub Actions workflows that automatically build Android and validate iOS on every push to `main`.

- Download **MechOS-Companion.apk** from the `MechOS-Companion-Android` workflow artifact for Android sideloading.
- The iOS workflow currently produces an **unsigned** build. A physical iPhone/TestFlight build requires Apple Developer signing credentials configured as GitHub Actions secrets.
- The application ID / bundle ID is `com.mechos.companion`.

See [`docs/BUILDING.md`](docs/BUILDING.md) for details.
